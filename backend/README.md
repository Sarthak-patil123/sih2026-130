# MAITRI 2.0 - Backend API & Services Scaffold

This directory is designated for server-side services, microservices, and micro-engines powering MAITRI 2.0:

- **Auth Service**: RBAC & Digital Signatures / Aadhaar / Digilocker e-Sign.
- **Rule Engine**: Dynamic single-window clearance dependency graph generator.
- **SLA & Notification Cron Engine**: Real-time statutory deadline countdowns & automated alerts.
- **Blockchain Gateway**: Hyperledger Fabric / SHA-256 state audit ledger node.
